# Repository-only skills

This directory contains skills used by this repository or personal workflows. They are intentionally separate from the public packages in [`../../skills/`](../../skills/) and are not included in the public marketplace or skills.sh indexes.

## Packages

- [`record`](./record/SKILL.md): Draft and save confirmed AI-related learning records and update the current AI context.
- [`reflect-tickets`](./reflect-tickets/SKILL.md): List and plan Reflect tickets for review.
- [`oliaolio-tickets`](./oliaolio-tickets/SKILL.md): List active Oliaolio tickets and propose execution plans.

Public skills remain under `skills/<skill-name>/SKILL.md`. Keep repository-only packages out of `.claude-plugin/marketplace.json`, `skills.sh.json`, and public installation examples.
